The third beta of **OpenVClient**, a free, open-source desktop app for databases, object storage and servers, for macOS, Windows and Linux. Website: [openvclient.xyz](https://openvclient.xyz).

> **This is a beta.** Please [report bugs](https://github.com/openvclient/openvclient/issues). Back up anything important before running destructive actions against production systems.

## What's new since beta 2

### A real file manager for cloud storage
Azure Blob Storage, Amazon S3 and S3-compatible providers (Backblaze B2, Cloudflare R2, Wasabi, IDrive e2, MinIO…), FTP/FTPS and SFTP now open in a file manager instead of a data table:
- **Back, Forward and Up** buttons and a **clickable breadcrumb** (connection › container › folder); double-click a folder to open it, Backspace to go up.
- A **file list** with type icons, readable sizes, local times and storage tier; sort by any column; select several files with Cmd/Ctrl or Shift.
- **Upload** (button or drag and drop from Finder / Explorer), **New folder**, **Download** (one file, or many into a folder), **Share link** (Azure SAS / S3 presigned), **Rename** (FTP/SFTP) and **Delete** with confirmation, also in a right-click menu. Read-only connections turn writes off.
- A **preview panel** for text and JSON files, with its own Download button.
- The sidebar shows folders only for these connections.

### Also new
- **About OpenVClient** (the info button next to Settings): version, **Check for updates**, links to the website, release notes and bug reports, and Copy version info. Settings shows the installed version.
- **New logo:** meet Vee, our friendly database. New app icon, installer artwork and in-app logo, with light and dark versions.
- **Readable dropdowns:** auth methods and options show proper names ("SAS (shared access signature)", "Microsoft Entra ID: interactive sign-in"…) instead of internal values.

### Fixed
- Cloud storage connections no longer show "localhost" in the sidebar; Azure shows the storage account, S3 the endpoint and bucket.
- Connector tiles in **New connection** are fully clickable; hovering the text no longer shows a text cursor or swallows the click.

### Upgrading
From beta 2, **OpenVClient tells you about this release itself** (About → Check for updates). Install over the top: the DMG replaces the app, the Windows setup upgrades in place, and `apt`/`dnf` upgrade the Linux packages. Your connections, saved passwords and history are kept. From beta 1, download it from this page (beta 1's update check skipped betas).

## What's inside

### Connectors
- **SQL:** PostgreSQL, MySQL, MariaDB, SQL Server / Azure SQL, SQLite, ClickHouse, plus Kingbase and GaussDB/openGauss presets (PostgreSQL protocol; not yet tested against those servers).
- **SQL Server sign-in:** SQL login, Windows/NTLM and integrated (Windows build), and Microsoft Entra ID: password, service principal, managed identity, device code, default credential chain, access token. Named instances via SQL Server Browser.
- **NoSQL and services:** MongoDB, Redis, Elasticsearch/OpenSearch, RabbitMQ (management API), Docker.
- **Servers and files:** SSH with an interactive terminal, SFTP browser and remote commands; FTP and FTPS (explicit and implicit TLS, client certificates).
- **Object storage:** Amazon S3 and S3-compatible providers (Backblaze B2, IDrive e2, Wasabi, Cloudflare R2, DigitalOcean Spaces, Google Cloud Storage via HMAC, Oracle, Linode, Scaleway, Hetzner, Storj, MinIO, Alibaba OSS), and Azure Blob Storage with every Storage Explorer sign-in method (account key, connection string, SAS, Entra ID, anonymous, Azurite).
- **Network paths** for TCP connectors: SSH tunnel (with jump hosts), SOCKS5 and HTTP CONNECT proxies.

### Working with data
- SQL editor with highlighting, autocomplete, tabs, run statement / selection / script, cancel, and history.
- **SSMS-style graphical execution plans** (cost per operator, row-count arrows) next to the classic plan tree.
- Virtualized results grid, inline editing with safe batched writes, CSV/JSON/SQL export, import.
- Object explorer (SSMS layout for SQL Server), DDL view, users and privileges, session and lock monitoring, metrics.
- Backup and restore via `pg_dump` / `mysqldump` / `mariadb-dump`, and SQL Server server-side backups.
- Folders and environments (Development / Testing / Staging / Production) with confirmation for destructive actions on production.
- ⌘K / Ctrl+K search across connections, objects and commands; dark and light themes.

### Security
- Passwords, keys, tokens and passphrases live only in the OS credential store (macOS Keychain, Windows Credential Manager, Linux Secret Service), never in plain files.
- SQL history and connection URIs with embedded passwords are encrypted at rest (AES-256-GCM, key in the credential store).
- SSH host keys are checked against `~/.ssh/known_hosts`; a new key is shown with its SHA-256 fingerprint and trusted only when you confirm it.
- Read-only connections, restore refuses dump files that would run shell commands, passwords are redacted from logs and error reports.
- Full findings and fixes: [docs/SECURITY_AUDIT.md](https://github.com/openvclient/openvclient/blob/main/docs/SECURITY_AUDIT.md).

### Help when things go wrong
- Plain-language explanations under connection errors ("nothing is listening on that port", "the server rejected the credentials"…), **Copy diagnostics**, and a log file you can open from Settings.
- In-app update check against GitHub Releases (can be turned off in Settings).

## Known limitations
- Kafka, Cassandra, Oracle, Db2 and JDBC are not available yet.
- SSH Kerberos/GSSAPI login is not supported.
- PostgreSQL/MySQL `require` TLS modes encrypt but do not verify the server certificate yet.
- Very large file transfers over FTP/SFTP/Azure are held in memory; Azure uploads over 4 GiB and S3 uploads over 5 GiB are refused (no multipart upload yet).
- Windows/integrated SQL Server sign-in and the Windows ARM64 build have not been tested on real hardware.
- The full list is in [docs/QA_REPORT.md](https://github.com/openvclient/openvclient/blob/main/docs/QA_REPORT.md).
