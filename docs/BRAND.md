# OpenVClient brand

The logo pairs **Vee**, a friendly database cylinder whose front is a bold **V** (for OpenVClient) that doubles as its smile, with the **OpenVClient** wordmark. It is drawn in the same cartoon infra style as the website: a yellow sticker tile, a thick outline and a hard offset shadow.

All files are in [`assets/brand/`](../assets/brand) and are generated by [`scripts/make-logo.py`](../scripts/make-logo.py). Change the script, not the SVGs.

| File | Use |
|------|-----|
| `openvclient-logo-light.svg` | Horizontal logo for light backgrounds (website header, docs, README) |
| `openvclient-logo-dark.svg` | Horizontal logo for dark backgrounds |
| `openvclient-logo-stacked-light.svg` / `-dark.svg` | Square-ish spaces: splash screens, slides, social avatars with text |
| `openvclient-mark-light.svg` / `-dark.svg` | The mark alone: app icon, favicon, small spaces |
| `openvclient-wordmark-light.svg` / `-dark.svg` | The name alone, where the mark already appears nearby |
| `favicon.svg` | Browser tab icon; switches its outline with the browser's light/dark theme |

**Light vs dark:** the light variants use an ink outline and ink shadow. The dark variants use a cream outline and a coral shadow, so the edge never disappears on dark backgrounds. The mark's face and V keep ink outlines in both, because they sit on the green body.

## Where it is used

- **App:** top bar and About panel (`theme::brand_mark` and `theme::wordmark`), with the variant picked from the app theme. The window, Dock and taskbar icon is `assets/icon/openvclient-256.png`.
- **Installers:** macOS `.icns` and DMG artwork, the Windows `.ico` and setup wizard images, and the Linux icon theme sizes, all generated by `scripts/make-icons.py` from `assets/icon/openvclient.png` (the light mark rendered at 1024 px).
- **Website:** header and footer logos, the favicon and the social preview image.

## Colours

| Name | Hex | Role |
|------|-----|------|
| Ink | `#1A1612` | Outlines, text on light |
| Cream | `#FFF7E6` | Paper background, outlines and text on dark |
| Sticker yellow | `#FFDB58` | Tile |
| Brand green | `#22C55E` | Vee's body, the V in the wordmark (also the app's accent) |
| Light green | `#86EFAC` | Vee's top |
| Teal | `#4ECDC4` | Sparkle |
| Coral | `#FF6B6B` | Shadow on dark backgrounds |

**Type:** the wordmark is IBM Plex Sans Bold (the app's UI font), converted to outlines. The website pairs it with Space Grotesk for headings and JetBrains Mono for labels and code.

## Rules

- Leave clear space around the logo equal to at least a quarter of the mark's height.
- Minimum sizes: the mark at 16 px, the horizontal logo at 24 px high.
- Do not recolour, stretch, rotate, add effects or separate the V's colour from the rest of the wordmark.
- Use the light variant on light backgrounds and the dark variant on dark ones. On photos or busy backgrounds, place the logo on a solid panel.

## Regenerating

```sh
python3 -m pip install fonttools          # once
python3 scripts/make-logo.py              # SVGs in assets/brand/
# render the light mark to assets/icon/openvclient.png (1024 px, transparent), then:
python3 scripts/make-icons.py             # app icons, installer artwork
```
